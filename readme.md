# Internal-Tech-Issue_Feature_Tracker API 🚀

A backend API for tracking internal technical issues and feature requests for software teams.

---

## 🌐 Live URL

- Live API:  https://internal-tech-issue-feature-tracker.vercel.app/
- GitHub Repository: https://github.com/ahsanrafi501/Internal-Tech-Issue-Feature-Tracker
---

## ✨ Features

- User Registration & Login
- JWT Authentication & Authorization
- Role-based Access Control
- Create Issue
- Update Issue
- Delete Issue
- Get All Issues
- Get Single Issue
- Issue Filtering & Sorting
- Password Hashing with bcrypt
- Centralized Error Handling
- PostgreSQL Database with Raw SQL

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- TypeScript
- PostgreSQL
- pg
- bcrypt
- jsonwebtoken
- dotenv
- cors
